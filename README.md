# Алгоритмы кластеризации с нуля

Обучение без учителя на данных о нью-йоркской аренде (Kaggle, NYC rental listings). Реализованы K-means и DBSCAN без готовых библиотечных классов, подобрано число кластеров, а метки кластеров использованы как новый признак для регрессии с оценкой качества и сравнением с реализациями из sklearn.

## Ключевая реализация
- Собственная реализация K-means: инициализация центроидов, пересчёт центров, присвоение кластеров, остановка по сходимости центроидов.
- Собственная реализация DBSCAN: параметризация радиуса окрестности и минимального числа соседей, выделение шума и выбросов.
- Подбор числа кластеров двумя эвристиками — методом локтя (distortion) и коэффициентом силуэта.
- Кластерные метки как признак в Lasso Regression с MinMaxScaler, интерпретация через веса модели.
- Сравнение всех методов по сложности, скорости и точности на разных наборах признаков.

## Стек технологий
- **Язык:** Python 3
- **Библиотеки:** NumPy (реализация алгоритмов), Pandas (предобработка), Scikit-learn (Lasso, MinMaxScaler, эталонные KMeans/DBSCAN/Agglomerative/GaussianMixture, метрики), Matplotlib (scatterplot, графики локтя и силуэта).

## Что реализовано
**1. Теоретическая часть:**
- Разбор схем инициализации центроидов (Forgy, Random Partition) с перечислением преимуществ и ограничений каждой.
- Объяснение, как кластеризация ускоряет KNN через предварительное сужение поиска по кластерам и kd-tree.

**2. Подготовка данных:**
- Предобработка из предыдущего урока, создание бинарных признаков дома (Elevator, Doorman, CatsAllowed и др.).
- Разделение на обучающую и тестовую выборки.

**3. K-means с нуля:**
- Кластеризация по географическим координатам (longitude, latitude) на 30 кластеров.
- Расчёт Silhouette score и Distortion, визуализация и анализ результата.
- Сравнение с `sklearn.cluster.KMeans`.

**4. Кластеры как признак:**
- Добавление метки кластера в Lasso Regression, вывод feature importance через веса модели.

**5. Другие алгоритмы:**
- DBSCAN с подбором параметров под качество итоговой модели.
- AgglomerativeClustering и GaussianMixture (EM) как альтернативы, сравнение с K-means.

**6. Разные наборы признаков и итоговое сравнение:**
- Кластеризация на комбинации bedrooms, bathrooms, interest_level.
- Сводное сравнение методов по вычислительной сложности, скорости и точности.

**7. Бонусная часть:**
- Замена Lasso на другие регрессионные модели.
- Оптимизация гиперпараметров для подбора числа кластеров.
- Комбинирование кластерных признаков из разных алгоритмов с последующим feature selection.

## Анализ результатов
- Коэффициент силуэта даёт более выраженную пиковую оценку числа кластеров, чем метод локтя, который при близких кластерах недооценивает k.
- K-means хорошо работает на сферических кластерах и требует задавать k заранее; DBSCAN находит кластеры произвольной формы и отсекает шум, но чувствителен к выбору радиуса и плотности; EM (GaussianMixture) мягко распределяет точки по кластерам, но сходится к локальному оптимуму и тоже зависит от инициализации.
- Иерархическая кластеризация не требует заранее задавать число кластеров, но дороже по памяти на больших выборках.
